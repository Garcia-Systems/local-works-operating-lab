# Part III summary — Sell the Right Problem

Part III turns an outward symptom into a disciplined decision without defaulting to software.

| Chapter | Gate question | Possible exit |
|---|---|---|
| 8 — Discovery | What is actually happening? | Problem not real → **STOP**; evidence gap → investigate only what matters. |
| 9 — Workflow Reconstruction | How does the work actually happen? | Problem misunderstood → **REFRAME**; workflow too uncertain → validate. |
| 10 — Problem Economics | What burden does the current workflow create? | Burden trivial → **STOP / LEAVE ALONE**; evidence weak → measure. |
| 11 — Qualification | Should Local Works continue? | No priority, no authority, wrong fit, infeasibility, or unacceptable risk → **STOP, NURTURE, REFER, DECLINE, or DISQUALIFY**. |

The chain is **Digital Friction Audit → Opportunity Gate → Discovery → Current-State Workflow → Problem Economics → Qualification Decision**. Every gate can prevent wasted customer and owner effort. Current burden is not recoverable value; technical possibility is not organizational or commercial feasibility; qualification is not solution selection or project approval.

Only an opportunity surviving these gates may enter **Part IV — Design the Right Solution**. Part IV has not been implemented here.
